## [0.1.0] - 2026-03-18

### Added
- Initial release of MCP Test Runner server
- Support for pytest, Jest, and Vitest test frameworks
- Content-hash caching to skip unchanged tests
- JUnit XML, Jest JSON, and Vitest JSON output parsers
- MCP protocol server with test execution tools
- Configurable test runner orchestration
